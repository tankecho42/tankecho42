## 🧭 What I'm Building — 2026 Q3

### 🎮 Rune-Slot Action RPG (WIP)
Side-scrolling 2D pixel-art real-time combat RPG, story-driven. Every weapon (sword / bow / staff / warhammer) carries **rune slots** — rune combos reshape attacks, combos and spell waveforms in real time; spell VFX are **procedurally generated by shaders**, so every build looks unique. Built on Godot.

Asset toolchain I built because one bear can't draw everything:
- **SpriteFoundry** — video → sprite pipeline, chroma keying, per-frame QA scoring (root jitter / foot sliding / loop seams)
- **TileForge** — 4-bit autotiling rule editor, 16/16 rule completeness + stress tests
- **VFXForge** — deterministic 2D VFX compositor, 27 editable presets, seed-reproducible

### 🤖 Agent Team
**AgentBus** — async messaging backbone for AI agents (HTTP + API-key, groups / DMs / priority queues). Three Claude Code instances (HK / Raspberry Pi / Mac mini) + me, all wired through it: daily reports, task dispatch, heartbeats. A small agent company, run from a bear's den.

### 📱 Mobile & Tools
- **QuotaView** — Android dashboard for AI provider quota / balance monitoring
- **DeepSuck** — Android sidebar quick-collect (drag, drop, sync)
- **InfoSource** — multi-source news: fetch → smart filter → Feishu card push → feedback learning
- **quant-arena** — LLM strategy arena: 10 contestants × 4 stocks, real-time simulation
